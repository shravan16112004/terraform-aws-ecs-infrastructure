# AWS Infrastructure Automation Using Terraform

This project automates a scalable and secure AWS infrastructure using Terraform.

## AWS Services Used

- VPC
- Public and Private Subnets
- Internet Gateway
- NAT Gateway
- Route Tables
- Security Groups
- Application Load Balancer
- ECS Cluster
- ECS EC2 Launch Type
- Auto Scaling Group
- ECS Service
- PostgreSQL RDS
- CloudWatch Logs

## Terraform Commands

```bash
terraform init
terraform validate
terraform plan
terraform apply
